# IL2CPP-Dumper-Python

A pure-Python toolkit for dumping Unity IL2CPP games. It extracts
method/type/string information from a game's `libil2cpp.so` +
`global-metadata.dat`, producing machine-readable JSON, a human-readable
`dump.cs`, and compilable per-assembly C# stubs (`DummyDll/`).

It handles real-world stripped Android binaries, XOR-protected metadata, and
custom-encrypted games (e.g. the `LIKEY` scheme) by reading the decrypted data
from a running game's memory.

**Core dumpers need only Python 3.8+** — no third-party packages, no phone,
no adb.

## Quickstart

```bash
# 1. place inputs in the standard folders (or use -b / -m / -g)
DumpPayload/lib/libil2cpp.so
DumpPayload/metadata/global-metadata.dat
# or: DumpPayload/apk/game.apk

# 2. run (no args = auto-discover from DumpPayload/)
python3 dumpers/dump_game.py

# 3. results land in a fresh timestamped folder:
#    DumpResult/2026-08-04_13-48-12/{script.json, dump.cs, DummyDll/, ...}
```

Equivalent explicit forms:

```bash
python3 dumpers/dump_game.py -g game.apk -o out/
python3 dumpers/dump_game.py -b libil2cpp.so -m global-metadata.dat -o out/
```

---

## Output

Each run writes to its own `DumpResult/<timestamp>/` folder (previous results
are never overwritten):

| File | What it is |
|---|---|
| `script.json` | Machine-readable: methods, strings, type infos, addresses |
| `stringliteral.json` | String literals with their addresses |
| `Strings.txt` | All metadata strings, one per line |
| `dump.cs` | Human-readable C# classes/methods |
| `DummyDll/` | Compilable per-assembly C# stubs (IDE intellisense) |

`dump.cs` and `DummyDll/` are generated by default; skip with
`--no-dump-cs` / `--no-dummy-dll`.

## Project layout

```
IL2CPP-Dumper-Python/
├── dumpers/        core dumpers
│   ├── dump_game.py          main dumper (script.json + dump.cs + DummyDll)
│   ├── dump_metadata.py      standalone global-metadata.dat parser
│   ├── dump_memory.py        rooted-device memory dumper (LIKEY bypass)
│   ├── frida_il2cpp_dump.py  Frida runtime (active-call) dumper
│   └── likey_dump.py         (legacy) Frida metadata scanner
├── tools/          utilities
│   ├── apk_probe.py          probe a remote APK's metadata version (no download)
│   ├── apkm_scrape.py        APKMirror download-chain scraper
│   ├── ida_annotate.py       apply names/comments in IDA
│   └── ghidra_annotate.py    apply names/comments in Ghidra
├── tests/          synthetic fixtures + regression sweep
├── docs/           INSTALL.md / USAGE.md / TESTING.md
├── DumpPayload/    input drop folder (apk/ lib/ metadata/ — git-ignored)
└── DumpResult/     output (auto-created, timestamped subfolders)
```

## Notes

- Validated against Perfare/Il2CppDumper output on multiple real 64-bit Unity
  games (byte-identical classes/members with attributes off).
- Windows/PE support (`GameAssembly.dll`) is experimental; the dumpers are
  tuned for Android ELF binaries.
- Real-game assets and dump outputs are git-ignored; only source and synthetic
  fixtures are committed.
